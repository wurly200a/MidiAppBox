# MidiAppBox 開発ワークフロー一巡チェック(check-workflow-routine)

まず CLAUDE.md を読み、全ルールに従うこと。

次に **docs/workflow.md(標準開発ワークフロー)を全体を通して読み、
その §4「一巡チェックモード」として実行すること。** 手順・不変条件・確認観点・
完了条件はすべて docs/workflow.md が原本であり、本ファイルには重複記載しない。

本ファイル固有の指定:

- 出力先タスク名: `captures/check-workflow-routine/`
- 実機での操作内容: 「なにかしらのアプリを実行する」でよい(metronome 推奨)。
- 新しい仕組み(スクリプト・ラベル・レイアウト)は作らない。
  変更してよいのは docs/dev-log.md への実施記録の追記のみ(workflow.md §4 どおり)。
- 手順の改善案を思いついた場合も、このチェック内では実施しない。
  チェック完走後に workflow.md §5 の形式(現行 → 提案、理由)で報告のみ行う。
